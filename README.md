# 📊 Superstore Sales Analysis | Power BI Dashboard

## 📌 Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Power BI to identify business trends, evaluate sales performance, and generate actionable insights.

The dashboard provides an interactive view of sales, profit, product performance, and regional trends to support data-driven business decisions.

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and sub-categories.
- Evaluate regional sales performance.
- Understand customer purchasing patterns.
- Identify trends and opportunities for business growth.
- Present key business insights through interactive dashboards.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and business metrics.
- **Excel** – Data source and preliminary analysis.
